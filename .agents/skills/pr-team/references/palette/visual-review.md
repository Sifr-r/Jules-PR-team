# Palette niche — Visual review

1. **Intent:** Identify the target surface, intended audience/task, requested design outcome, and decisions to preserve. Review only that scope and candidate. An audit returns observations and proposals without edits; a design/refinement assignment permits only its owned changes.
2. **Questions:** Does the rendered result support the brief's hierarchy, visual character, primary action, and content density? What is the most consequential observed mismatch? Which concerns are behavioral defects, requested design acceptance gaps, or optional subjective preferences? Keep those classes separate; aesthetic disagreement alone does not establish defect severity.
3. **Evidence:** Inspect current source and available render evidence together. When a safe runnable target exists, record the exact candidate, route, state, browser, viewport, theme, and motion preference for captures. Include relevant content extremes and loading/error/empty states, not just a hero screenshot. Prefer final build evidence when the repository supports it safely. Existing screenshots need a freshness check against current implementation; do not present them as newly executed browser checks. Judge composition before using automated findings as suggestions. Screenshots show appearance; keyboard, focus, behavior, and assistive-technology support need their own evidence.
4. **Bounded action and proof:** Rank concrete gaps by impact on the assigned outcome. For authorized work, fix the highest-impact issues in a coherent batch, then inspect the integrated result and affected neighboring states. Explain the change against the brief and preserved system, without arbitrary numeric taste scores. Every edit consumes the coordinator's existing two-batch lifecycle; this niche grants no extra repair or screenshot/fix loop. Missing browser capability permits an explicitly limited source/available-image review, not invented render success or mandatory dependency installation.
5. **Stop and handoff:** Stop when assigned acceptance is evidenced, the coordinator's batch limit is reached, or missing evidence prevents judgment. Report remaining gaps and exact unrun checks. Hand behavioral defects to the relevant niche/Scalpel, regression coverage to Harness, and independent readiness to Gatekeeper; never certify your own implementation as the final gate.

Informative sources: [Taste Skill render review](https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/SKILL.md), [Impeccable critique](https://github.com/pbakaus/impeccable/blob/main/skill/reference/critique.md). No runtime fetch required.
