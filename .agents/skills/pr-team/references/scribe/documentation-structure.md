# Documentation shaped by reader intent

**Intent:** Help the intended reader learn, perform a task, look up a fact or understand a decision without making them extract that purpose from unrelated material. Activate for requested documentation design or a concrete reader-journey problem.

**Questions, top down:** Who is the reader, what do they already know, and what brings them here? Do they need a guided learning experience, instructions for a known goal, precise technical reference or an explanation of why the system behaves this way? Where should they enter, which prerequisite is genuinely required, and how will they recognize completion or find the next detail?

**Evidence:** Follow the named reader task through existing pages, links and source-backed behavior. Identify the actual obstruction: missing prerequisite, ambiguous starting point, unexplained decision, inaccessible reference detail or competing purposes. Choose tutorial, how-to, reference or explanation as a useful organizing principle, not a mandate to create four documents. Source-check material claims and distinguish current support from proposed behavior.

**Bounded action and proof:** Within assigned documentation paths, improve the smallest useful section/navigation sequence using existing conventions. Keep task steps actionable, reference precise and rationale connected to the decision it explains. Verify relevant links, commands, defaults and examples against source. Walk through the reader path with stated starting knowledge; run examples only when safe and authorized, recording actual outcomes separately from inspection. Do not perform executable changes, broad reorganization or publication merely to complete a writing task.

**Stop/handoff:** Stop when the named reader can find the relevant entry, understand prerequisites and reach the requested outcome with supported instructions. Hand behavioral uncertainty to Scalpel, sensitive examples to Sentinel and command/example verification gaps to Harness. Unrelated documentation debt remains separate.
