# Capability research and provenance

Checked against primary sources on **30 October 2026**. These are research inputs for independently written PR Team guides, not installed or vendored skills. No upstream scripts, assets, binaries, or instruction files are bundled. This contributor ledger is deliberately outside `references/` and is not included in launcher prompts. Active guides are local and self-contained; their source links do not require network access during a task.

Links to moving branches describe the material inspected on that date, not immutable dependencies. Recheck the source and its applicable notices before copying or installing anything in a future change. A source's popularity is not evidence that its workflow fits this project or improves generated output.

## Verification limits

Reading these sources and checking guide packaging does not measure generated UI quality, performance, security, or live agent execution. Instruction simulations can expose routing and authority contradictions. Claims of improved output require actual task evidence; reported screenshots, browser tests, timings, contract results, and publication receipts must come from the candidate that was really evaluated.
